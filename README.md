# Avail
Availability App

Team availability web app: share one link, everyone marks when they're free, and confirmed sessions land in each person's calendar.

- Plan and notes: [docs/Home.md](docs/Home.md) (the `docs/` folder is an Obsidian vault)
- Google Sheets version used today: [tools/google-sheets/availability.gs](tools/google-sheets/availability.gs)
